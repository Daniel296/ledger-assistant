# Ledger Assistant

A read-only assistant for the double-entry ledger in [ledger-api](https://github.com/Daniel296/ledger-api). You ask, in
a web chat, why an account has its balance or what happened to a transaction; the assistant reads the ledger through an
MCP server and answers with the ledger's own numbers. It never writes, and it never computes an amount.

Work in progress.
